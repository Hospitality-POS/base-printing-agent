PrintAgent portable package for Windows 7/8/8.1/10/11

Option 1 - Run without installing:
1. Extract this folder.
2. Double-click START-PRINTAGENT.bat.
3. The setup page should open in your browser at http://127.0.0.1:14200

Option 2 - Install to the machine:
1. Extract this folder.
2. Double-click INSTALL-PRINTAGENT.bat.
3. It copies PrintAgent to %LOCALAPPDATA%\PrintAgent, creates Desktop and Start Menu shortcuts, enables startup at login, and opens setup.

If nothing opens, run START-PRINTAGENT-DEBUG.bat and keep the window open. Any startup error will be shown there.
